# SkillDiscovery 🎯

An Android application built with **Jetpack Compose** that helps users discover and share skills.

---

## 📱 Tech Stack

| Layer | Technology |
|---|---|
| Language | Kotlin |
| UI | Jetpack Compose + Material 3 |
| Image Loading | Coil |
| Fonts | Google Fonts |
| Min SDK | 24 (Android 7.0) |
| Target SDK | 35 (Android 15) |

---

## 🚀 Getting Started

### Prerequisites

- Android Studio Hedgehog or newer
- JDK 11+
- Android SDK 35

### Clone & Run

```bash
git clone https://github.com/<your-username>/SkillDiscovery.git
cd SkillDiscovery
```

1. Open the project in **Android Studio**
2. Let Gradle sync complete
3. Run on an emulator or physical device (API 24+)
